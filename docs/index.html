📝 Sample Test Implementation

BookingServiceTest.java
@ExtendWith(MockitoExtension.class)
class BookingServiceTest {

    @Mock
    private BookingRepository bookingRepository;

    @Mock
    private RoomRepository roomRepository;

    @InjectMocks
    private BookingService bookingService;

    @Test
    void shouldCreateBookingSuccessfully() {
        // Given
        BookingRequestDto request = new BookingRequestDto();
        // Setup request data...

        // When
        when(roomRepository.findById(anyLong())).thenReturn(Optional.of(new Room()));
        when(bookingRepository.save(any(Booking.class))).thenReturn(new Booking());

        // Then
        BookingResponseDto result = bookingService.add(request);
        assertThat(result).isNotNull();
        verify(bookingRepository).save(any(Booking.class));
    }
}

🔧 Troubleshooting

Common issues dan solusinya

❌ Common Problems & Solutions

🚨 Database Connection Issues

Problem:

java.sql.SQLException: Access denied for user 'root'@'localhost'

Solutions:

  • Check MySQL service is running: brew services start mysql (macOS) atau sudo systemctl start mysql (Linux)
  • Verify username/password di application.properties
  • Grant proper permissions: GRANT ALL PRIVILEGES ON *.* TO 'root'@'localhost';
  • Check database exists: CREATE DATABASE tutorial_spring;
⚠️ Port Already in Use

Problem:

Port 8080 was already in use

Solutions:

  • Kill process using port: lsof -ti:8080 | xargs kill -9
  • Change port di application.properties: server.port=8081
  • Use different profile dengan port berbeda
⚠️ Build Failures

Problem:

Maven build failing atau dependency issues

Solutions:

  • Clean maven cache: mvn clean
  • Reload dependencies: mvn dependency:resolve
  • Check Java version: java -version (should be 21+)
  • Verify JAVA_HOME: echo $JAVA_HOME

📝 Code Examples

✅ Good Practice - Service Implementation

Good Service Implementation
@Service
@RequiredArgsConstructor
@Transactional
public class BookingService {
    
    private final BookingRepository bookingRepository;
    private final RoomRepository roomRepository;
    private final BookingMapper bookingMapper;
    
    public BookingResponseDto add(BookingRequestDto requestDto) {
        // 1. Validate business rules
        validateBookingRequest(requestDto);
        
        // 2. Check room availability
        Room room = findAvailableRoom(requestDto.getRoomId());
        
        // 3. Create booking entity
        Booking booking = bookingMapper.toEntity(requestDto);
        booking.setRoom(room);
        booking.calculateTotalAmount();
        
        // 4. Save and return response
        Booking savedBooking = bookingRepository.save(booking);
        return bookingMapper.toResponseDto(savedBooking);
    }
    
    private void validateBookingRequest(BookingRequestDto request) {
        if (request.getCheckInDate().isAfter(request.getCheckOutDate())) {
            throw new ValidationException("Check-in date must be before check-out date");
        }
    }
}

❌ Bad Practice Example

Bad Practice - Avoid This
// ❌ Bad: Controller with business logic
@PostMapping
public ResponseEntity createBooking(BookingRequest req) {
    // Business logic in controller - BAD!
    if (req.checkIn.after(req.checkOut)) {
        return ResponseEntity.badRequest().body("Invalid dates");
    }
    
    // Direct database access - BAD!
    Booking b = new Booking();
    b.setCustomer(req.customer);
    em.persist(b);
    
    return ResponseEntity.ok(b);
}
